# درست‌نویس

ابزاری برای بررسی و اصلاح خودکار متن فارسی، بر پایهٔ **دستور خطّ فارسی (ویراست دوم، فرهنگستان زبان و ادب فارسی، ۱۴۰۴)**.

هر پیشنهاد به بند و صفحهٔ منبعش ارجاع می‌دهد، تا نویسنده بداند چرا باید چیزی را عوض کند.

```
قبل: رييس اداره گفت كه این مساله را بررسي می کنیم و نتیجه ی آن را اعلام می کنیم.
بعد: رئیس اداره گفت که این مسئله را بررسی می‌کنیم و نتیجۀ آن را اعلام می‌کنیم.
```

## بسته‌ها

| بسته | وضعیت | توضیح |
|---|---|---|
| [`textlint-rule-preset-farhangestan`](packages/textlint-rule-preset-farhangestan) | در حال ساخت | قواعد املای رسمی (دستور خط فرهنگستان) برای [textlint](https://textlint.org) |
| پیش‌تنظیم شکسته‌نویسی | برنامه‌ریزی‌شده | گفت‌وگوی داستان، بر پایهٔ *اصول شکسته‌نویسی* (علی صلح‌جو) |
| سایت | برنامه‌ریزی‌شده | متن را بگذارید، پیشنهادها را ببینید و بپذیرید |

## معماری

۱. **یکدست‌سازی نویسه‌ها**: «ی/ک» فارسی، نیم‌فاصلهٔ درست، ارقام. کاملاً قطعی است.
۲. **قاعده‌ها**: هر بند دستور خط یک قاعدهٔ textlint، با مثال‌های خود کتاب به‌عنوان آزمون.
۳. **واژه‌نامه**: فهرست‌های کتاب و فرهنگ املایی، برای کلمه‌هایی که قاعدهٔ کلی ندارند.
۴. **لایهٔ مدل زبانی (برنامه‌ریزی‌شده)**: فقط برای مواردی که به تشخیص نیاز دارد، و فقط به‌صورت پیشنهاد.

اصل طراحی: **دقت مهم‌تر از پوشش.** پیشنهاد غلط از پیشنهاد جاافتاده بدتر است.

## توسعه

```sh

```
