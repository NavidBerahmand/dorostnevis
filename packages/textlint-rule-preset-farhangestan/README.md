# textlint-rule-preset-farhangestan

قواعد **دستور خطّ فارسی (ویراست دوم، فرهنگستان زبان و ادب فارسی، ۱۴۰۴)** برای [textlint](https://textlint.org).

این پیش‌تنظیم متن فارسی را می‌خواند، خطاهای املایی و فاصله‌گذاری را گزارش می‌کند و بیشترشان را خودکار اصلاح می‌کند. کنار هر پیام، بند و صفحهٔ دستور خط آمده است.

الگوی ساختار: [textlint-rule-preset-JTF-style](https://github.com/textlint-ja/textlint-rule-preset-JTF-style)؛ هر بند راهنما یک قاعده، و مثال‌های خود کتاب آزمون قاعده‌اند.

## نمونه

```
قبل: رييس اداره گفت كه این مساله را بررسي می کنیم و نتیجه ی آن را اعلام می کنیم.
بعد: رئیس اداره گفت که این مسئله را بررسی می‌کنیم و نتیجۀ آن را اعلام می‌کنیم.
```

## نصب و استفاده

```sh
npm install --save-dev textlint textlint-rule-preset-farhangestan
```

`.textlintrc.json`:

```json
{
  "rules": {
    "preset-farhangestan": true
  }
}
```

```sh
npx textlint متن.md          # گزارش
npx textlint --fix متن.md    # اصلاح خودکار
```

### گزینه‌ها

```json
{
  "rules": {
    "preset-farhangestan": {
      "plural-ha": { "mode": "required-only" },
      "ezafe-he": { "style": "he-hamza" },
      "normalize-characters": { "digits": false },
      "lexicon": { "dictionaries": { "hamza": false } }
    }
  }
}
```

- `plural-ha.mode`: `recommended` (پیش‌فرض؛ جدانویسی توصیه‌شدهٔ کتاب) یا `required-only` (فقط موارد الزامی، مثل «خانه‌ها»).
- `ezafe-he.style`: `he-yeh` (پیش‌فرض، «ۀ» مثل خود کتاب) یا `he-hamza` («هٔ»).
- `lexicon.dictionaries`: هر فهرست (`multiSpelling`، `compounds`، `hamza`) را می‌شود خاموش کرد.

## اصل طراحی: دقت مهم‌تر از پوشش

پیشنهاد غلط از پیشنهاد جاافتاده بدتر است. برای همین:

- شکل پیوسته («میرود»، «بیدلیل»، «بزرگتر») فقط وقتی اصلاح می‌شود که خود کلمه در واژه‌نامهٔ Hazm نباشد و شکل درستش باشد. برای همین «میدان»، «میلاد»، «بیمار»، «دفتر» و «دیمیتری» دست نمی‌خورند. این بررسی روی همهٔ واژه‌های Hazm اجرا شده و هیچ واژهٔ درستی را عوض نمی‌کند.
- استثناهای کتاب همیشه بر داده‌های Hazm مقدّم‌اند (Hazm «بی‌هوش» و «بی‌عار» دارد، کتاب «بیهوش» و «بیعار»).
- «تر» فقط وقتی «از» بعدش آمده اصلاح می‌شود، چون «لباس تر» هم درست است.
- واژه‌هایی که در کتاب با حرکت آمده‌اند (آخُر، غُرُق) هرگز اصلاح نمی‌شوند، چون بی‌حرکت کلمهٔ دیگری‌اند (آخر، غرق).
- هر قاعده روی متن خودِ کتاب دستور خط اجرا و خطاهای کاذبش رفع شده است.
- هر جا درستی به معنا بستگی دارد («رفت و آمد» ← «رفت‌وآمد» فقط در معنای اصطلاحی؛ «خانهای» که هم «خانه‌ای» است هم «خان‌های»)، فقط گزارش می‌شود و اصلاح خودکار ندارد.
- فهرست واژه‌هایی که کتاب صریحاً پیوسته نوشته (`src/dict/book-joined.json`) بر همهٔ قواعد خودکار مقدّم است.

## داده‌ها

- `src/dict/multi-spelling.json` با `scripts/extract_multi_spelling.py` از فایل docx کتاب ساخته می‌شود (pandoc لازم است). خود کتاب در این مخزن نیست.
- `src/dict/hazm-*.json` (ستاک‌های فعل، صفت‌ها، جفت‌های «بی-») با `scripts/build_hazm_data.py` از داده‌های [Hazm](https://github.com/roshan-research/hazm) (مجوز MIT) ساخته می‌شوند.
- بقیهٔ فایل‌های `src/dict` دستی و از روی فهرست‌های کتاب نوشته شده‌اند.

```sh
python3 scripts/extract_multi_spelling.py کتاب.docx > src/dict/multi-spelling.json
pip download hazm --no-deps -d /tmp/hazm
python3 scripts/build_hazm_data.py /tmp/hazm/hazm-*.whl
```
