# textlint-rule-preset-shekaste

قواعد شکسته‌نویسی در **گفت‌وگوی داستان**، بر پایۀ *اصول شکسته‌نویسی* (علی صلح‌جو، نشر مرکز، ۱۳۹۳). همراه با `textlint-rule-preset-farhangestan` به کار می‌رود: املای کلمه‌ها همچنان تابع دستور خط است و این پیش‌تنظیم فقط می‌گوید کدام کلمه را شکسته بنویسیم.

قاعدۀ **کاهش هجا** در کتاب (فقط کلمه‌ای شکسته نوشته شود که در گفتار یک هجا کم می‌کند؛ «نان»، نه «نون») از نسخۀ ۱.۶.۲ واج‌بان دنبال نمی‌شود: «نون، خونه، دیگه، اومدم، کتابا، یه» همان‌طور که نوشته می‌شوند درست‌اند (بانک واژه‌های محاوره‌ای، `textlint-rule-preset-farhangestan/src/util/colloquial-bank.ts`). فقط املای خود شکل شکسته بررسی می‌شود.

| قاعده | چه می‌کند | اصلاح خودکار |
|---|---|---|
| `over-broken` | شکل کلمه حفظ شود: «خالهم، تهش» ← «خاله‌م، ته‌ش» (ص ۲۱ و ۴۲)؛ «تش» ← «ته‌ش» (پیشنهاد) | بله برای نیم‌فاصله |
| `may-break` | جاهایی که شکستن رواست: «می‌روم» ← «می‌رم»، «سرد است» ← «سرده»، «صدایم» ← «صدام»، «چگونه» ← «چطوری»، «مرا» ← «من را»، «از من» ← «ازم»، «به من» ← «به‌ام»، «کی است» ← «کیه»، «مهندسین» ← «مهندس‌ها»، «چه می‌خوای» ← «چی می‌خوای» | نه، فقط پیشنهاد |
| `spoken-spelling` | املای شکل شکسته: «میگه، میرم، میدم» ← «می‌گه، می‌رم، می‌دم» (نیم‌فاصلۀ «می» در شکسته هم لازم است)؛ «توصورتم» ← «تو صورتم» (پیشنهاد) | بله برای «می» |
| `spoken-word` | (`formalRules`، برای جمله‌های رسمی یک متن) واژۀ شکسته در جملۀ رسمی: «گرون» ← «گران»، «دیگه» ← «دیگر»، «می‌خوام» ← «می‌خواهم» (فقط وقتی شکل نوشتاری روشن است) | نه، فقط پیشنهاد (آبی) |
| `spoken-ra` | (`commonRules`، در هر جمله) «رو» ← «را» یا «روی»، «اون» ← «آن» یا «او»، «اونو» ← «آن را» یا «او را»؛ نه در «از این رو»، «رو به»، «زیر و رو» | نه، فقط پیشنهاد (آبی) |

## توسعه

```sh
npm test   # در همین پوشه
```

قواعد از `../textlint-rule-preset-farhangestan/src/util` استفاده می‌کنند؛ برای همین آزمون‌ها با `test/register.cjs` اجرا می‌شوند. پیش از انتشار جداگانه در npm، این کد مشترک باید بستۀ جدا شود.
