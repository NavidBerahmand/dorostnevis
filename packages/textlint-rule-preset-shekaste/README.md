# textlint-rule-preset-shekaste

قواعد شکسته‌نویسی در **گفت‌وگوی داستان**، بر پایۀ *اصول شکسته‌نویسی* (علی صلح‌جو، نشر مرکز، ۱۳۹۳). همراه با `textlint-rule-preset-farhangestan` به کار می‌رود: املای کلمه‌ها همچنان تابع دستور خط است و این پیش‌تنظیم فقط می‌گوید کدام کلمه را شکسته بنویسیم.

قاعدۀ اصلی کتاب، **کاهش هجا**: فقط کلمه‌ای که در گفتار یک هجا کم می‌کند شکسته نوشته می‌شود («می‌روم» ← «می‌رم»)؛ کلمه‌ای که تعداد هجایش عوض نمی‌شود کامل نوشته می‌شود و خواننده خودش آن را شکسته می‌خواند («نان»، نه «نون»).

| قاعده | چه می‌کند | اصلاح خودکار |
|---|---|---|
| `over-broken` | «نون، خونه، دیگه، اگه، نیس، یه» ← «نان، خانه، دیگر، اگر، نیست، یک»؛ «کتابو» ← «کتاب را»؛ «بهش، بهشون» ← «به‌اش، به‌شون»؛ «هنوزم» ← «هنوز هم»؛ «بفرمایین» ← «بفرمایید»؛ «خارجن» ← «خارج‌اند»؛ «خالهم، تهش» ← «خاله‌م، ته‌ش»؛ «می‌خورن، می‌گن» ← «می‌خورند، می‌گند»؛ «رفته‌ان» ← «رفته‌اند»؛ «اومدم» ← «آمدم»؛ «کتابا» ← «کتاب‌ها»؛ «بخونمش، نمی‌دونم، موند» ← «بخوانمش، نمی‌دانم، ماند» | بله |
| `may-break` | جاهایی که شکستن روا و توصیه‌شده است: «می‌روم» ← «می‌رم»، «سرد است» ← «سرده»، «صدایم» ← «صدام»، «چگونه» ← «چطوری»، «مرا» ← «من را»، «از من» ← «ازم»، «به من» ← «به‌ام»، «کی است» ← «کیه»، «مهندسین» ← «مهندس‌ها»، «چه می‌خوای» ← «چی می‌خوای» | نه، فقط پیشنهاد |
| `spoken-spelling` | املای شکل شکسته: «میگه، میرم، میدم» ← «می‌گه، می‌رم، می‌دم» (نیم‌فاصلۀ «می» در شکسته هم لازم است)؛ «توصورتم» ← «تو صورتم» (پیشنهاد) | بله برای «می» |
| `spoken-word` | (`formalRules`، برای جمله‌های رسمی یک متن) واژۀ شکسته در جملۀ رسمی: «گرون» ← «گران»، «چمدون‌های» ← «چمدان‌های» | نه، فقط پیشنهاد (آبی) |

«اون»، «اونو»، «رو» و «صب» دو خوانش دارند و فقط گزارش می‌شوند.

## توسعه

```sh
npm test   # در همین پوشه
```

قواعد از `../textlint-rule-preset-farhangestan/src/util` استفاده می‌کنند؛ برای همین آزمون‌ها با `test/register.cjs` اجرا می‌شوند. پیش از انتشار جداگانه در npm، این کد مشترک باید بستۀ جدا شود.
