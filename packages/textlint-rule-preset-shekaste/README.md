# textlint-rule-preset-shekaste

قواعد شکسته‌نویسی در **گفت‌وگوی داستان**، بر پایهٔ *اصول شکسته‌نویسی* (علی صلح‌جو، نشر مرکز، ۱۳۹۳). همراه با `textlint-rule-preset-farhangestan` به کار می‌رود: املای کلمه‌ها همچنان تابع دستور خط است و این پیش‌تنظیم فقط می‌گوید کدام کلمه را شکسته بنویسیم.

قاعدهٔ اصلی کتاب، **کاهش هجا**: فقط کلمه‌ای که در گفتار یک هجا کم می‌کند شکسته نوشته می‌شود («می‌روم» ← «می‌رم»)؛ کلمه‌ای که تعداد هجایش عوض نمی‌شود کامل نوشته می‌شود و خواننده خودش آن را شکسته می‌خواند («نان»، نه «نون»).

| قاعده | چه می‌کند | اصلاح خودکار |
|---|---|---|
| `over-broken` | «نون، خونه، دیگه، اگه، نیس، یه» ← «نان، خانه، دیگر، اگر، نیست، یک»؛ «کتابو» ← «کتاب را»؛ «بهش» ← «بهاش»؛ «می‌خورن، می‌گن» ← «می‌خورند، می‌گند»؛ «رفته‌ان» ← «رفته‌اند»؛ «اومدم» ← «آمدم»؛ «کتابا» ← «کتاب‌ها»؛ «بخونمش، نمی‌دونم، موند» ← «بخوانمش، نمی‌دانم، ماند» | بله |
| `may-break` | جاهایی که شکستن روا و توصیه‌شده است: «می‌روم» ← «می‌رم»، «سرد است» ← «سرده»، «صدایم» ← «صدام»، «چگونه» ← «چطوری» | نه، فقط پیشنهاد |

«اون»، «اونو»، «رو» و «صب» دو خوانش دارند و فقط گزارش می‌شوند.

## توسعه

```sh
npm test   # در همین پوشه
```

قواعد از `../textlint-rule-preset-farhangestan/src/util` استفاده می‌کنند؛ برای همین آزمون‌ها با `test/register.cjs` اجرا می‌شوند. پیش از انتشار جداگانه در npm، این کد مشترک باید بستهٔ جدا شود.
